Recorrido

  1. Vacío (ver): campo con ejemplo y sugerencias para empezar.
  2. Cargando (ver): señal de espera "Pensando…".
  3. Respuesta (ver): respuesta corta con su fuente debajo.
  4. Error (ver): mensaje honesto, reintentar y salida a una persona.
  5. Persona (ver): datos para hablar con alguien del equipo.

Camino feliz y camino de error

Camino feliz: Vacío → Cargando → Respuesta con fuente.
Camino de error: Vacío → Cargando → Error → Reintentar o Hablar con una persona.
En todas las pantallas hay aviso de límites y botón para hablar con una persona.

Aviso de límites y control humano

  • El aviso "Respuestas generadas con IA: pueden contener errores" está a la vista en todas las pantallas, no en letra pequeña.
  • El botón "Hablar con una persona" aparece en todas las pantallas.
  • Temas delicados (garantías con reclamos, devoluciones de dinero, decisiones sobre una persona): el asistente deriva siempre a una persona.
